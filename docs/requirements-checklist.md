# Official requirements checklist

From the Space Apps "Project Submission Guide" and "Judging & Awards Guide", read on 2026-11-14.

## Disqualifying if missed

- [ ] **Everything in English:** project page and every linked material (website, slides, this repository). Only exception: the video may be spoken in another language with English subtitles
- [ ] **Demo: video of at most 30 seconds** (team chose video over the 7-slide option)
- [ ] **Public links:** demo and final project open without password, permission or sign-up. Test in a private window
- [ ] Click **"Submit for Judging"** before Sunday 2026-11-15, 23:59 local event time (internal deadline 22:00; confirm with the Local Lead)
- [ ] All required fields filled and both boxes checked (terms; original work with references listed)
- [ ] All members registered at the same local event and visible in the Members tab (max 6; cannot be added after closing)
- [ ] No images, video or audio of people under 18
- [ ] At least one NASA dataset or resource used (required for global awards)

## Project page fields (in English)

- [ ] Project Name
- [ ] High-Level Project Summary
- [ ] Link to Project Demo
- [ ] Link to Final Project
- [ ] Detailed Project Description
- [ ] Use of AI
- [ ] NASA Data
- [ ] Space Agency Partner Data and Other References

Images: JPG, PNG or GIF up to 10 MB. Videos and documents only by link. The page can be saved and resubmitted; the last saved version counts. **Submit a first version early on Sunday as insurance.**

## Use of AI

- [ ] AI used to speed up work, not to create the solution idea
- [ ] AI-generated code and data declared in the README and in file headers
- [ ] AI-generated images and videos carry a visible watermark
- [ ] No generated content uses or modifies NASA marks

## On the site

- [ ] Statement: "Independent hackathon project. Not an official NASA product and not endorsed by NASA."
- [ ] "Not a mission certification" notice visible on results

## Judging criteria (1 to 5 each)

| Criterion | Where the project answers it |
|---|---|
| Impact | Two modes (school and expert) |
| Creativity | Provenance transparency; data panel |
| Validity | LOLA + Horizons calculation; validation table |
| Relevance | Sun and Earth against each site's real horizon, NASA data at the core |
| Presentation | Project page text and 30 s demo |

Most of the score comes from the submission page, not the demo.
