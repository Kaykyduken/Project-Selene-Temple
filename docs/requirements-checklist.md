# Official requirements checklist

From the Space Apps submission guide, read on 2026-11-14. Breaking a hard limit can disqualify the project.

## Language

- [ ] Project page in English
- [ ] Every linked material in English, including the website and this repository
- [ ] Video may be in Portuguese **only** with English subtitles

## Demo (hard limit)

- [ ] Video of **at most 30 seconds** (team chose video over the 7-slide option)

## Project page

- [ ] Written with care: the project page weighs more than the demo in judging
- [ ] All external references listed (data, libraries, images, tools)
- [ ] Use of AI declared

## Use of AI

- [ ] AI used as a tool only; the solution idea comes from the team
- [ ] AI-generated code identified in the README
- [ ] AI-generated code identified in a header comment in each affected file

## Links and content

- [ ] All links public, no login required
- [ ] No images of people under 18

## Judging criteria (1 to 5 each)

- Impact
- Creativity
- Validity
- Relevance
- Presentation
